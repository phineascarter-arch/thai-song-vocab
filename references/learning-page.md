# 歌曲學習頁

這份 skill 不依賴追劇版檔案；可依以下規格直接產生單一 HTML。以奶油紙色、墨綠、少量金色與手帳卡片延續原學習頁風格，桌面多欄、手機單欄，深淺色可切換。不要沿用 Girl Rules、EP01、固定 Part 數或 47 張卡等示範內容。

## 同一份資料產生全部成果

歌曲 metadata 至少包含穩定 `songId`（歌手、歌名、版本）、標題、歌手、版本、來源 URL、來源類型、內容範圍（使用者提供範圍／可完整處理／精選摘要）與音訊限制。

先確認 SKILL.md 的可交付歌詞範圍，才放入 sections 與 cards。sections 描述可交付段落的字面意思、自然翻譯、意象解讀；重複段落透過 references／出現位置對照，不複製整段。不同文字的副歌要區分。未知唱法填未核對，不產生假節奏資料。

每張卡的 schema：

```json
{
  "id": "stable-card-id",
  "sectionId": "section-1",
  "thai": "核對後且可交付的詞句",
  "meaning": "繁中自然意思",
  "literal": "字面意思",
  "split": "學習斷詞",
  "gloss": "逐詞繁中",
  "romanization": "按音節的教學羅馬拼音",
  "tones": ["低", "中"],
  "hint": "長短母音、送氣與尾音提示",
  "usage": "詩意語法與日常可用性",
  "interpretation": "意象解讀；推論須標明",
  "singingNote": "實際聽音才描述，否則標未核對",
  "occurrences": [{"sectionId": "section-1", "timeSeconds": null}],
  "sourceUrl": "實際來源連結",
  "audio": null
}
```

`null` 代表未提供，不是製作假資料的許可。音訊完成才填入 MP3 data URI。句子有疑義時保留解釋中的不確定性並排除 Anki／語音。

## 互動與資料保護

- 顯示歌曲版本、來源、內容範圍、學習重點與拼音圖例。摘要版不能以「完整逐句翻譯」命名。
- 搜尋泰文、繁中與羅馬拼音；依實際段落、收藏、未學會篩選。重複副歌只出現一張卡，詳細頁列重現段落／已核對時間點。
- 詳細頁分開顯示自然意思、字面義、逐詞、拼音、聲調、發音提示、日常用法、意象解讀與唱法限制。不要把旋律音高寫進標準口語聲調。
- 正常／慢速語音依 [女聲流程](voice.md)。只有真實時間碼才產生定位連結，沒有則回來源影片。
- 收藏／學會與深淺色存 localStorage，key 使用 `thai-song:{songId}:{dataVersion}`；每張卡用穩定 ID 索引，不能使用追劇版的 key。匯入進度先檢查 songId、版本與 ID，不把別首歌紀錄混入。
- 支援隱藏中文自測、隨機複習、最多五題的選擇題。依篩選結果抽題，去除同義或重複的答案選項；題目不足減量，沒有題目提示調整篩選。
- 可匯出 Markdown、兩欄 Anki CSV、JSON 進度並匯入進度。CSV 從同一份卡片資料產生，正確轉義引號與換行。Anki 的文字 CSV 不宣稱自帶音檔；要可匯入的音訊媒體時需另行打包並驗證。
- 將歌詞視為文字，以 textContent 等安全方式呈現。JSON 內嵌時轉義 `<` 為 `\u003c`，防止 `</script>` 提早結束。單檔不依賴 CDN、外部腳本或工作目錄。
- iPhone 窄螢幕測試長泰文、拼音、導覽及播放器溢出；鍵盤可搜尋、開關詳細頁與揭示中文。localStorage 無法使用時仍能讀卡，提示備份限制。

## 驗證

資料可解析；ID 唯一；重複副歌去重；段落、卡數、CSV 一致；只保留可交付歌詞範圍。檢查 JS 語法、拼音音節與聲調數、MP3 解碼及受影響互動。操作至少涵蓋搜尋、段落篩選、詳細頁、正常／慢速、隱藏中文、收藏／進度重載、測驗結果與匯出讀回。未測的功能如實標示。

用本機伺服器測試後停止自己啟動的程序，交付實際 HTML 檔。使用者另有要求才發布 GitHub Pages 或其他網站。
