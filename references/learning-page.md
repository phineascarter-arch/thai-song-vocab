# 歌曲學習頁

這份 skill 不依賴追劇版檔案；可依以下規格直接產生單一 HTML。以奶油紙色、墨綠、少量金色與手帳卡片延續原學習頁風格，桌面多欄、手機單欄，深淺色可切換。不要沿用 Girl Rules、EP01、固定 Part 數或 47 張卡等示範內容。

## 同一份資料產生全部成果

歌曲 metadata 至少包含穩定 `songId`（歌手、歌名、版本）、標題、歌手、版本、來源 URL、來源類型、內容範圍（使用者提供範圍／可完整處理／精選摘要）與音訊限制。

先確認 SKILL.md 的可交付歌詞範圍，才放入 sections 與 cards。sections 描述可交付段落的字面意思、自然翻譯、意象解讀；重複段落透過 references／出現位置對照，不複製整段。不同文字的副歌要區分。未知唱法填未核對，不產生假節奏資料。

每張卡的 schema：

```json
{
  "id": "stable-card-id",
  "sectionId": "section-1",
  "thai": "核對後且可交付的詞句",
  "meaning": "繁中自然意思",
  "literal": "字面意思",
  "split": "學習斷詞",
  "gloss": "逐詞繁中",
  "romanization": "按音節的教學羅馬拼音",
  "tones": ["低", "中"],
  "hint": "長短母音、送氣與尾音提示",
  "usage": "詩意語法與日常可用性",
  "interpretation": "意象解讀；推論須標明",
  "singingNote": "實際聽音才描述，否則標未核對",
  "occurrences": [{"sectionId": "section-1", "timeSeconds": null}],
  "sourceUrl": "實際來源連結",
  "audio": null,
  "words": [{"thai": "已核對的教學詞塊", "romanization": "按音節的教學羅馬拼音", "meaning": "當句繁中詞義", "audio": null}]
}
```

`null` 代表未提供，不是製作假資料的許可。音訊完成才填入 MP3 data URI。句子有疑義時保留解釋中的不確定性並排除 Anki／語音。

## 互動與資料保護

- 顯示歌曲版本、來源、內容範圍、學習重點與拼音圖例。摘要版不能以「完整逐句翻譯」命名。
- 搜尋泰文、繁中與羅馬拼音；依實際段落、收藏、未學會篩選。重複副歌只出現一張卡，詳細頁列重現段落／已核對時間點。
- 詳細頁分開顯示自然意思、字面義、逐詞、拼音、聲調、發音提示、日常用法、意象解讀與唱法限制。不要把旋律音高寫進標準口語聲調。
- 正常／慢速語音依 [女聲流程](voice.md)。只有真實時間碼才產生定位連結，沒有則回來源影片。
- 收藏／學會與深淺色存 localStorage，key 使用 `thai-song:{songId}:{dataVersion}`；每張卡用穩定 ID 索引，不能使用追劇版的 key。匯入進度先檢查 songId、版本與 ID，不把別首歌紀錄混入。
- 支援隱藏中文自測、隨機複習、最多五題的選擇題。依篩選結果抽題，去除同義或重複的答案選項；題目不足減量，沒有題目提示調整篩選。
- 可匯出 Markdown、兩欄 Anki CSV、JSON 進度並匯入進度。CSV 從同一份卡片資料產生，正確轉義引號與換行。Anki 的文字 CSV 不宣稱自帶音檔；要可匯入的音訊媒體時需另行打包並驗證。
- 將歌詞視為文字，以 textContent 等安全方式呈現。JSON 內嵌時轉義 `<` 為 `\u003c`，防止 `</script>` 提早結束。單檔不依賴 CDN、外部腳本或工作目錄。
- iPhone 窄螢幕測試長泰文、拼音、導覽及播放器溢出；鍵盤可搜尋、開關詳細頁與揭示中文。localStorage 無法使用時仍能讀卡，提示備份限制。

## 驗證

資料可解析；ID 唯一；重複副歌去重；段落、卡數、CSV 一致；只保留可交付歌詞範圍。檢查 JS 語法、拼音音節與聲調數、MP3 解碼及受影響互動。操作至少涵蓋搜尋、段落篩選、詳細頁、正常／慢速、隱藏中文、收藏／進度重載、測驗結果與匯出讀回。未測的功能如實標示。

用本機伺服器測試後停止自己啟動的程序，交付實際 HTML 檔。使用者另有要求才發布 GitHub Pages 或其他網站。

## 逐詞拆解的獨立發音

沿用追劇版的詞塊播放方式，但此 skill 必須自足，不讀取另一個 skill 的檔案才能運作。每張卡的 `words` 與 `split`／`gloss` 一一對齊，依教學詞塊切分，多音節詞整個播放，不按泰文字母亂切。配對數量不符先核對，不讓詞與中文錯位。

將每個詞顯示成可點按按鈕：泰文、當句中文及播放圖示；aria-label 使用「單字發音：{thai}」。每個不同詞塊使用自己的 Premwadee MP3 data URI，跨卡同詞可去重；無音訊時停用並說明，不能拿整句音檔冒充單字音檔。

點詞時停止前一段音訊並從頭以正常速度播放；單字、整句與慢速共用原生 audio 播放器，避免重疊。點過單字後再按「正常／慢速發音」，必須重新載入目前整句的 audio，不能仍播放剛才的單字。切卡或關閉詳細頁時停止舊音訊。播放錯誤在詳細頁內顯示，iPhone 直接由點按觸發，不等待網路合成。

實測至少一張多詞卡的每個按鈕、不同詞的不同音檔、播放進度與錯誤狀態，以及單字切回整句／慢速；不能把按鈕出現等同於播放成功。既有三行歌詞對照、收藏、字卡 ID 與進度 key 保留。

## 完整歌詞的每行學習

使用者提供全文並要求完整學習版時，所有原文行都須有：原文、羅馬拼音、自然繁中、正常／慢速口語語音、可展開的詳細詞塊解釋，以及詞塊各自的獨立發音。不要只完成精選字卡或歌名卡就宣稱逐句學習完成。重複副歌可共用資料與音訊，但原文每次出現仍保留學習入口。

每行分為有意義的泰語詞／詞塊，標明各詞意思及句中作用；拼接拆解後應覆蓋該行全部文字（忽略排版空白與標點），不漏掉語氣詞。保留英文混用、音譯與聽寫疑義，另外註記；韓語音譯不得說成標準泰文。句子的標準口語合成不代表原唱唱法。

詞塊音檔與完整句子音檔分開，採相同 Premwadee 女聲。用去重 audio bank 以穩定 ID 參照，避免在重複副歌及詞塊位置反覆嵌入相同 base64。播放某行或單詞前停止其他播放器；單詞播放後按本句正常／慢速必須切回該行全文音檔。每行提供原生控制與錯誤提示，不只在頁尾顯示錯誤。資料量大可預載 none，不自動播放。

驗證每行都有音檔與非空拆解、原文完整覆蓋、音訊參照有效；選不同位置的行測詞塊切換、正常／慢速切回整句與避免重疊。沒有通過原唱時間碼對齊驗證時，不宣稱逐字卡拉 OK 自動同步。

拆解卡片固定由上至下顯示「泰文 → 該詞的羅馬拼音 → 當句繁中詞義／作用」，`words[].romanization` 不可省略，也不能只在整句上方提供拼音。完整歌詞每行與精選字卡兩處皆套用；英文保留英文，韓語音譯另註明，沿用全文同一套拼寫。修改文字排列不更動音訊或進度 ID。
